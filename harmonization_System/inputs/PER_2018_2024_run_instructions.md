## Key coding decisions (document here)

### Migration
- **migrante_ci**: `p401g2 < 10000` → born in foreign country. Codes < 10,000 are district codes (Peruvian districts); codes ≥ 10,000 are country codes for foreign-born respondents.
- **migrantiguo5_ci**: Used `p401f` (lived in this district 5 years ago?) + `p401g` (where lived 5 years ago).
- **mig_pais_ci**: Only Venezuela (code 4037) explicitly mapped; all others → "Otro". To expand mapping, check codebooks for full country code list.

### Education
- **aedu_ci**: Used `grados = rowtotal(p301b p301c)` for all waves (consistent with 2024 reference). Note: MECOVI scripts for 2018-2022 used a different conditional approach, but p301b and p301c are stable across all waves.

### Labor — cotizando_ci
**IMPORTANT DECISION**: Scripts use `p524b1` and `p538b1` (actual pension contribution amounts) for 2018–2023, following the MECOVI reference approach for those years.

**Alternative option**: The dictionary check confirmed `p558b2` (year of last pension contribution) exists in all 7 waves. An alternative construction for 2018-2023 would be:
```stata
destring p558b2, replace    // p558b2 is stored as string in raw data
replace cotizando_ci=1 if (p558a1==1 | p558a2==2 | p558a3==3 | p558a4==4) & p558b2==2018  // or ==2019, etc.
```
This would match the 2024 reference logic exactly. However, it was NOT validated against the MECOVI reference for earlier waves. Use p524b1/p538b1 as the safe default.

### Labor — relacion_ci (2018 only)
- `p203==11` condition NOT included in 2018 script (per MECOVI 2018 reference).
- Starting 2019: `p203==11` is included in category 4 (otros parientes).

### Hours — horastot_ci (2019–2022 only)
- `replace p518 = . if p518 == 99` added before horastot_ci rsum.
- 2018 and 2023+ do not have this non-response code.

| `variable p538b1 not found` | p538b1 not in merged DTA | Same as above |
